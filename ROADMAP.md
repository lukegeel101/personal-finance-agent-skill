# Roadmap

This roadmap keeps development concrete while preserving the project's read-only and approval-gated safety model.

## Now

- Expand deterministic reconciliation and recurring-charge fixtures.
- Strengthen source-coverage and evidence-status reporting.
- Improve contribution templates and newcomer documentation.

## Next

- Add more connector-neutral import adapter examples.
- Add synthetic budget, debt, and portfolio evaluation fixtures.
- Add explicit conflict-resolution reports for disagreeing sources.

## Later

- Publish an interoperability guide for additional agent runtimes.
- Add optional local encrypted persistence interfaces.
- Explore privacy-preserving evaluation against larger synthetic account histories.

## Non-goals

- Submitting payments, transfers, trades, applications, or cancellations without explicit authorization.
- Storing credentials, account identifiers, or real financial records in the repository.
- Presenting estimates, plans, or stale snapshots as confirmed facts.

Open an issue before beginning a large roadmap item so scope, evidence, and safety assumptions can be reviewed first.
