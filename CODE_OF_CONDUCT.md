# Code of Conduct

## Our standard

We want this project to be a welcoming place for constructive, evidence-based collaboration.

Be respectful, assume good intent, give actionable feedback, and keep discussions focused on the work.

Harassment, discriminatory conduct, personal attacks, threats, doxxing, and deliberate exposure of private or financial data are not acceptable.

## Scope

This standard applies in repository issues, pull requests, discussions, reviews, and other spaces used to represent the project.

## Reporting

Report conduct, security, or privacy concerns privately through the process described in [SECURITY.md](SECURITY.md).

Project maintainers may remove content or restrict participation when behavior conflicts with this standard.

This policy is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
